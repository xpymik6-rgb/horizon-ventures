Graphviz in Confluence Cloud: free and paid options

Confluence Cloud does not render DOT on its own. Which apps do, what they cost for a small team, and the one case none of them covers well: a diagram generated outside Confluence whose node links must stay clickable. Checked on a live Confluence Cloud site on 23 October 2026.

Short answer. Confluence Cloud has no built-in Graphviz macro, so you need an app. If you want to write DOT directly on the page, install Graphviz Diagrams for Confluence by Appfire: it is the long-standing Graphviz app, runs on Atlassian's current Forge platform, was updated in September 2026, and is free for sites with up to 10 users. If your diagrams are generated somewhere else (a script, a build pipeline, a docs-as-code repository) and you only need to show the resulting SVG with working links, read the section on attached SVG files below.

For most teams the choice is between the first two. Appfire's app is the Graphviz specialist, with macros that build a graph from a Confluence table or from the page tree of a space. Just Add+ makes sense if Graphviz is one of several text formats you want on your pages.

Clickable nodes

Graphviz can attach a link to any node, edge or cluster with the URL attribute, and a hover text with tooltip:

digraph services {
  rankdir=LR;
  node [shape=box, style="rounded,filled", fillcolor="#eef3fb"];
  web [label="Web app",  URL="https://example.com/web", tooltip="Web app runbook"];
  api [label="API",      URL="https://example.com/api", tooltip="API docs"];
  db  [label="Database", URL="https://example.com/db",  tooltip="Schema"];
  web -> api -> db;
}

Inside Appfire's macros this works in Cloud: their Cloud documentation, How to add links to graphviz images, shows URL and tooltip on nodes and edges, and even Confluence-style links such as [Page title|SPACE] as targets. For the other apps in the table we did not test whether node links stay clickable, so try it on one diagram before you rely on it.

When the SVG is made outside Confluence

Many teams do not write DOT in Confluence at all. The diagram is generated: a script draws the service map from a config file, a build job runs dot -Tsvg services.dot -o services.svg, a tool exports its dependency graph. The SVG then gets attached to a Confluence page, and the links Graphviz put on every node are the whole point of it.

We tested exactly that. We rendered the DOT above with real Graphviz, confirmed that the SVG contains three links with their tooltips, attached it to a page on a Confluence Cloud test site and inserted it the normal way, as an image. Confluence displayed it as a flat picture (an <img> element): the diagram looks right, but none of the nodes can be clicked and the tooltips are gone. This is the same behaviour we describe in why Confluence Cloud turns your SVG into a flat image, and it is how browsers treat any SVG shown as an image, not a Graphviz problem.

Your options here:

  • Keep the DOT source and paste it into one of the apps above, so the app renders it on the page with links. Fine if the diagram changes rarely.
  • Link to the SVG file itself under the image, so people who need the links open it in a new tab. Free, but most readers will not.
  • Show the attached SVG with an app that keeps its links.

Disclosure: I build Clickable SVG for Confluence, which does the third. In the same test, the same attached file shown through our macro kept all three node links and their tooltips, and the reader can zoom and search inside the diagram. It does not render DOT: it shows an SVG you already have. It is free for teams of up to 10 people, then $2 per user per month. If you write your diagrams on the page, Appfire's Graphviz app is the better fit, and if your case is simpler than clickable nodes, take the free option.

Frequently asked

Does Confluence Cloud support Graphviz natively?

No. There is no built-in macro for DOT source in Confluence Cloud. You need an app.

Is there a free Graphviz app for Confluence Cloud?

Yes, for small sites. Appfire's Graphviz app, Just Add+ and Kroki Diagrams are free for sites with up to 10 users.

Why are the links in my Graphviz SVG not clickable in Confluence?

Because Confluence shows an attached SVG as an ordinary image, and an image cannot contain working links. Render the DOT with a Graphviz app, or show the SVG with an app that keeps links.
