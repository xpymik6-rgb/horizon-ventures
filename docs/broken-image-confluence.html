Broken image in Confluence Cloud: what the placeholder tells you

An image that used to be there is now a grey box. Confluence does not say why, but the box itself is a clue: there are three different placeholders, and each one points to a different cause. We built a test page with every case on a live Confluence Cloud site in October 2026 and looked at what each one shows.

Short answer. A grey box with a file icon and a "preview unavailable" message means the image's attachment is missing from the page, usually because someone deleted it; restore it from the space trash. The same box with a picture icon means the image is linked from an outside address that no longer answers; upload the image to the page instead. A small grey "unknown attachment" label means the image came from another page that has been deleted; restore that page from the trash or re-upload the image here.

The three placeholders

What you seeCauseFix
Grey box, file icon, preview unavailableThe attachment is not on the page: deleted, or never uploadedRestore it from the space trash, or upload the file again
Grey box, picture icon, preview unavailableThe image is an external link and the address no longer returns an imageSave the image and upload it to the page as an attachment
Small grey "unknown attachment" labelThe image is an attachment of another page, and that page was deletedRestore the other page from the trash, or upload the image to this page

Our test site runs in Russian, so the English wording of the messages may differ slightly; the icons and the shape of each placeholder are what to go by.

Two details from the test that save time. A deleted attachment and one that was never uploaded look exactly the same, so the trash is the only way to tell them apart. And a working external image displays normally, so a picture icon in the box really does mean the outside address is the problem, not Confluence.

Getting a deleted image back

Deleting an attachment does not destroy it straight away. In our test the deleted file appeared in the space trash, listed by name together with the page it came from, with a Restore action next to it. Confluence asks for a confirmation, and after that the image was back on the page in place of the grey box. The deleted page behind an "unknown attachment" label was in the same list. The trash for a space is at:

https://your-site.atlassian.net/wiki/pages/viewtrash.action?key=SPACEKEY

Replace SPACEKEY with the space key from the page address. Once someone empties the trash, the file is gone for good, and the only way back is a site backup or the original file.

If you have many pages and want to know which ones lost an image, the REST API lists a page's trashed attachments with GET /wiki/api/v2/pages/{id}/attachments?status=trashed; on our test page it returned exactly the deleted file.

Why external images break

An image inserted from a web address is not copied into Confluence; every reader's browser fetches it from that address each time. When the other site moves the file, takes it down or blocks outside use, the picture disappears from your page, and nobody on your side changed anything. For anything that has to stay, download the image and upload it to the page: then it lives in Confluence with the page.

What we could not test

Images on pages with restrictions. Our test site is on the Free plan, which has no page restrictions, so we could not check what a reader without access to the source page sees. If an image is broken for one colleague and fine for you, permissions are the first thing to look at.

For SVG files that show up as a flat picture with dead links rather than a broken one, see why Confluence Cloud turns your SVG into a flat image. That one is not a fault but how Confluence shows SVG.

Frequently asked

Why is an image broken on my Confluence page?

The attachment was deleted, the external address died, or the image came from a page that was deleted. The placeholder tells you which.

Can I restore a deleted image?

Yes, from the space trash, until someone empties it.

What does "unknown attachment" mean?

The image belongs to another page that no longer exists. Restore that page or upload the image again.
